# COURTSIDE IQ
Dedicated NBA + EuroLeague data laboratory, installed in a separate folder of the SIDELINE repository so SIDELINE remains unchanged.

Vercel project root directory: `courtside-iq`, framework: Other, build command: `npm run build`, output: `.`.

This distribution contains the complete original source in `source.br.b64` (Brotli-compressed JSON file-map). Run `npm run build` to reconstruct readable project source files. After unpacking, the application has player/team stats, comparisons, forecasts, and a transparent NBA/EuroLeague source-status layer.

No live feed is guaranteed; providers can deny access. Monte Carlo is an educational statistical simulation, not a calibrated betting model. README details and source file comments are reconstructed by the build.
